# My Workout / Mój Trening

Bilingual 12-week training checklist PWA (48 workouts) with exercise checkmarks, optional top weight and total reps, local backup, and the Friends Challenge leaderboard.

**Current status:** Friends progress comparison uses manual exchange of progress codes. The notification preferences UI is ready, but **push notifications and automatic friends sync are not enabled**. They require a secure backend and user opt-in.

## GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Open the Pages URL in Safari on iPhone, choose Share → Add to Home Screen. The PWA can work offline after its assets are cached.

## Data and privacy

Each person's records are held in their own device's local browser storage. Use Settings → Export before moving from an older hosting URL; local storage is separate per website address. Never place credentials or Supabase service-role keys in the public repository.

Training exercises have been adapted from the PDF the owner supplied.
